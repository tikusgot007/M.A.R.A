# AGENTS.md — M.A.R.A

Repo ini adalah catatan ide + memory konteks kerja AAN.

## WAJIB dibaca lebih dulu
Sebelum menjawab atau mengerjakan apa pun di sesi ini, baca:
- `MEMORY.md` — konteks project, infra, hubungan antar-repo, keputusan.

Kalau ada info baru penting dari diskusi, perbarui `MEMORY.md`. Tujuannya: user tidak perlu menjelaskan ulang dari awal tiap sesi.

## Aturan
- Bahasa: Indonesia.
- **Setiap kali user bicara dan ada info/keputusan/fakta baru: langsung perbarui `MEMORY.md` (append/update) sebelum menjawab.** Jangan biarkan info hanya di chat.
- **Cara bertanya ke user: SATU pertanyaan per waktu, dengan opsi pilihan (pakai tool `question`).** User tinggal memilih, tidak perlu mengetik bebas.
- Ide baru masuk ke `ideas/` (satu file per ide) atau ke `IDEAS.md`.
